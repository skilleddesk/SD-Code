# protocol/ — SDCP schema

SDCP is the protocol between the SDC app and a host daemon (`sdcd`): an envelope, methods,
notifications, an event catalogue, capabilities, migration rules and an HTTP API surface
(spec §5). The full definition lives in the **v2.0 protocol document**, which is *not* in this
repository yet — that is why this directory contains only this README in STEP 1.

## Rules this directory will follow

1. **Schema-first (spec §5.10).** The JSON Schema files are the single source of truth. The
   Rust types in `sdcd/` and the TypeScript types consumed by `app/` are *generated* from
   them — never hand-written, never edited in place.
2. **One event log, one reducer.** The protocol is append-only; the UI is a pure reducer over
   events (spec §3.2). Anything the UI draws must be derivable from the event catalogue.
3. **Versioned, additive changes.** Envelope/SDCP versions move only by the migration rules in
   spec §5.7; the app reports the protocol version in Settings (prototype: `SDCP 0.1`).

## Planned layout (created in STEP 2, when the v2.0 spec arrives)

```
protocol/
├── schema/            # JSON Schema, one file per envelope/method/event group
│   ├── envelope.schema.json
│   ├── methods.schema.json
│   └── events.schema.json
├── src/               # generated TypeScript types (checked in, regenerated by a script)
│   └── index.ts
├── package.json       # added to the pnpm workspace at the same time
└── README.md
```

Until then: nothing in this repository may invent SDCP shapes. If a UI module needs a field
that the protocol does not define yet, the field is added to the v2.0 document first.
