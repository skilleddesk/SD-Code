# মালিকের কাছ থেকে যা লাগবে (0.16.1)

কোড সম্পূর্ণ, টেস্ট পাস, commit করা। নিচের জিনিসগুলো আপনার মেশিন, আপনার অ্যাকাউন্ট বা আপনার
সিদ্ধান্ত ছাড়া করা যায় না। যখন সময় হবে আমাকে দেবেন বা জানাবেন, তারপর আমি যাচাই করে রিপোর্ট দেব।

## ১. লোকাল মডেল (Ollama): বাধ্যতামূলক, লাইভ যাচাইয়ের জন্য

এই কম্পিউটারে এখনো Ollama ইনস্টল নেই। কোডের পথ একটা নকল Ollama সার্ভার দিয়ে পরীক্ষা করা হয়েছে
(টুল-কলিং, `num_ctx`, স্ট্রিম, এরর)। কিন্তু **আসল মডেলের সাথে চালানো হয়নি।**

আপনি যা করবেন:

1. https://ollama.com থেকে Ollama ইনস্টল করুন।
2. টার্মিনালে লিখুন: `ollama pull qwen3.5:9b` (৬–৭ GB নামবে)।
3. জানাবেন আপনার গ্রাফিক্স কার্ডে কত VRAM আছে (যেমন 8 GB)।

তারপর আমি যা যাচাই করব:

- SDC-তে Local গ্রুপ থেকে `Qwen3.5 9B` বেছে একটা সাধারণ প্রশ্ন, আর একটা ফাইল পড়ার কাজ।
- `ollama ps`-এর CONTEXT কলামে 16384 দেখায় কিনা (মানে `num_ctx` সত্যিই পৌঁছেছে), আর PROCESSOR-এ
  100% GPU কিনা।
- `/research` দিয়ে ৩–৪টা প্রশ্ন, বাংলা ও Banglish মিলিয়ে: সোর্স আসে কিনা, সীমায় থামে কিনা, আর
  উত্তর না পেলে অনুমান না করে "পাওয়া যায়নি" বলে কিনা।
- VRAM কম হলে Settings → Research → Local model context কমিয়ে (যেমন 8192) আবার চালানো।

## ২. সার্চ সার্ভিসের API key: ঐচ্ছিক

DuckDuckGo কোনো key ছাড়াই চলে, আর এটাই ডিফল্ট। ভালো মানের ফলাফল আর তারিখ চাইলে নিচের যেকোনো
একটার key Settings → Research-এ দিন (key সিস্টেমের কী-চেইনে থাকে, কোথাও লেখা হয় না):

| সার্ভিস | ফ্রি | কোথায় পাবেন |
|---|---|---|
| Serper (Google) | ২,৫০০ সার্চ, এককালীন | serper.dev |
| Tavily | মাসে ১,০০০ | tavily.com |
| Brave Search | মাসে $5 ক্রেডিট (কার্ড লাগে) | brave.com/search/api |
| SearXNG | অসীম (নিজের সার্ভার) | settings.yml-এ `json` format চালু করতে হবে |

key দিলে আমি সেই সার্ভিস দিয়ে লাইভ সার্চ যাচাই করব। এখন শুধু নকল SearXNG সার্ভার দিয়ে টেস্ট করা হয়েছে।

## ৩. চূড়ান্ত উত্তরের জন্য API মডেল: ঐচ্ছিক

Settings → Research → Final answer model। লোকাল মডেল পেজ পড়ে সারাংশ করবে, আর এখানে বাছা API মডেল
(যেমন DeepSeek) চূড়ান্ত উত্তর লিখবে। এতে খরচ হয়, শুরুর আগের কার্ডে আনুমানিক খরচ দেখায়। চাইলে
আপনার DeepSeek key দিয়ে এটা লাইভ যাচাই করব।
