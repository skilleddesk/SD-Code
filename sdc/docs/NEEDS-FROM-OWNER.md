## যা এখনো বাকি / আপনার সিদ্ধান্ত

1. **চূড়ান্ত উত্তরের জন্য API মডেল** (Settings → Research → Final answer model): ঐচ্ছিক, এখনো লাইভ যাচাই হয়নি।
   চাইলে DeepSeek বেছে একবার `/research` চালিয়ে দেখব।
2. **ছোট মডেলের সীমা:** 9B মডেল মাঝে মাঝে পেজের কথা ভুল সারাংশ করে, যেমন ভুল সময় বা অচেনা নাম।
   তাই প্রতিটা দাবির পাশে `[n]` আর নিচে সোর্সের তালিকা থাকে, মিলিয়ে দেখার জন্য।
   গুরুত্বপূর্ণ প্রশ্নে Final answer model চালু করা ভালো।
3. **গতি:** আপনার কার্ডে অন্য অ্যাপ মিলিয়ে প্রায় ৭.৭ GB আগে থেকেই ব্যবহৃত। তাই মডেলের কিছু অংশ CPU-তে চলে।
   ধীর লাগলে অন্য GPU অ্যাপ বন্ধ রাখুন, বা Settings → Research → Local model context 8192 করুন।
4. **`background.rs`-এর পুরনো টেস্ট:** আগে থেকে থাকা, commit-না-করা `starting_past_max_running_is_refused_until_one_stops`
   টেস্ট পাশের আরেকটা টেস্টের সাথে একসাথে চললে ফেল করে। আমি ছুঁইনি। রাখবেন কিনা জানাবেন।
