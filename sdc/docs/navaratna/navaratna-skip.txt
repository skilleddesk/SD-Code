ধাপ ১ - আপনার Windows মেশিন মডেলের জন্য যথেষ্ট কি না দেখুন
------------------------------------------------------------------------------------------------
[Windows] PowerShell-এ:
     "{0:N1} GB RAM" -f ((Get-CimInstance Win32_ComputerSystem).TotalPhysicalMemory / 1GB)
     Get-CimInstance Win32_VideoController | Select-Object Name, @{n="VRAM_GB";e={[math]::Round($_.AdapterRAM/1GB,1)}}
     nvidia-smi          (NVIDIA কার্ড থাকলে; ঠিক VRAM দেখায়। "AdapterRAM" ৪ GB-র বেশি ঠিকমতো দেখায় না)
     Get-PSDrive C | Select-Object @{n="FreeGB";e={[math]::Round($_.Free/1GB)}}
সিদ্ধান্ত (আমার হিসাব ও এই Mac-এর অভিজ্ঞতা থেকে, Windows-এ যাচাই করিনি):
  - qwen3.5:9b ফাইল ৭.৬ GB। চলার সময় ফাইল + প্রসঙ্গ-স্মৃতি (১৬K প্রসঙ্গে প্রায় ২.৫ GB) = প্রায় ১০ GB লাগে।
  - ১৬ GB বা বেশি RAM, অথবা ১২ GB-র বেশি VRAM-এর NVIDIA কার্ড: 9B চালানো যাবে। কার্ড ছাড়া শুধু CPU হলে চলবে কিন্তু ধীর (প্রতি ধাপে কয়েক মিনিট)।
  - ৮ GB RAM: 9B লোডই হবে না। qwen3.5:4b (৪.০ GB) চলে কিন্তু খুব ধীর, পরীক্ষার উপযোগী নয়।
  - ডিস্কে অন্তত ২০ GB খালি রাখুন।
  - পরীক্ষার সময় ব্রাউজার ও ভারী অ্যাপ বন্ধ রাখুন।

ধাপ ২ - দরকারি প্রোগ্রাম ইনস্টল করুন

২.১ SDC নতুন ভার্সন [Windows]
   ব্রাউজারে https://github.com/skilleddesk/SD-Code/releases/latest খুলে "Assets" থেকে নামান:
     SDC_1.1.1_x64-setup.exe   (সবচেয়ে সহজ)     অথবা     SDC_1.1.1_x64_en-US.msi
   ডাবল-ক্লিকে ইনস্টল। "অপরিচিত প্রকাশক" (SmartScreen) দেখালে "More info" -> "Run anyway" (ইনস্টলার সই করা নয়)।
   মেলানো (ঐচ্ছিক): একই পাতার SHA256SUMS.txt নামান, তারপর
     Get-FileHash $HOME\Downloads\SDC_1.1.1_x64-setup.exe -Algorithm SHA256
   যে সংখ্যা আসবে তা SHA256SUMS.txt-এ ওই ফাইলের পাশের সংখ্যার সাথে হুবহু মিলতে হবে।
   !! 1.1.0 নামাবেন না - ওতে একটি বাগ ছিল (ধাপের লক্ষ্য "1." দেখাত)। 1.1.1-এ ঠিক করা।
   Mac: SDC_1.1.1_aarch64.dmg (Apple Silicon) / SDC_1.1.1_x64.dmg (Intel)
   Linux: SDC_1.1.1_amd64.AppImage / .deb / SDC-1.1.1-1.x86_64.rpm
   আগে 1.0.x বা 1.1.0 থাকলে নতুনটা ইনস্টল করলেই আপডেট হয়ে যায়।

২.২ Ollama (লোকাল মডেল চালানোর প্রোগ্রাম)
   সহজতম: SDC নিজেই ইনস্টল করে দেয় - SDC খুলে মডেল-হাবে ("Local models" ট্যাব ও "Environment doctor" ট্যাব) এক ক্লিকে।
   হাতে করতে চাইলে [Windows]:
     winget install Ollama.Ollama
     (না পারলে https://ollama.com/download থেকে OllamaSetup.exe)
   তারপর PowerShell বন্ধ করে নতুন খুলুন, এবং:
     ollama --version
   [Mac]  brew install ollama      [Linux]  curl -fsSL https://ollama.com/install.sh | sh
   নোট: SDC সবসময় 127.0.0.1:11434 পোর্টে Ollama খোঁজে (বদলানো যায় না)। OLLAMA_HOST অন্য কিছু দেবেন না।

২.৩ Python + pytest (নিচের ডেমো পরীক্ষার জন্য) [Windows]
     winget install Python.Python.3.12
     PowerShell নতুন খুলে:   python --version
     python -m pip install pytest
   (Microsoft Store-এর `python3` নাম ব্যবহার করবেন না; SDC Windows-এ `python` নামই চালায়।)

২.৪ Git: SDC নিজেই একটি ছোট Git এনে নেয়। তবু নিজের জন্য:   winget install Git.Git
   (git shadow/checkpoint সুবিধার জন্য Git দরকার।)

ধাপ ৩ - মডেল নামান ও চালিয়ে দেখুন
------------------------------------------------------------------------------------------------
[সব]  (কয়েক GB নামবে; ইন্টারনেট ও জায়গা লাগবে)
     ollama pull qwen3.5:9b
     ollama list
     ollama show qwen3.5:9b
  - "quantization" লাইনে Q4_... দেখালে: SDC মডেল-তালিকায় পরামর্শ দেখাবে এবং প্রতি ধাপের লক্ষ্য ৮০% থেকে ৬০%-এ নামাবে।
    বেশি মেমরি থাকলে Q5_K_M/Q8_0 সংস্করণ নিন (ট্যাগের নাম https://ollama.com/library/qwen3.5-এ দেখুন; আমি ট্যাগের নাম যাচাই করিনি)।

     ollama run qwen3.5:9b "say hello in one word"
  উত্তর এলে ঠিক। বের হতে /bye। না এলে নিচের "সমস্যা-সমাধান" দেখুন।
  পোর্ট দেখতে [Windows]:   Invoke-RestMethod http://127.0.0.1:11434/api/tags | ConvertTo-Json -Depth 3

ধাপ ৪ - sdcd কমান্ডটা খুঁজে নিন (ধাপ ৫, ৮, ১০-এ লাগবে)
------------------------------------------------------------------------------------------------
sdcd হলো SDC-র ইঞ্জিন; অ্যাপের সাথেই ইনস্টল হয় (সাধারণত sdcd.exe নামে, SDC.exe-র পাশে; নামটা আমি Windows-এ যাচাই করিনি)।
[Windows] খুঁজুন:
     Get-ChildItem -Path "$env:LOCALAPPDATA","$env:ProgramFiles" -Recurse -Filter "sdcd*.exe" -ErrorAction SilentlyContinue | Select-Object -First 3 FullName
   যে পথ আসবে সেটা দিয়ে (পথটা নিজেরটা বসান; একবার চালালে এই PowerShell জানালার জন্য থাকে):
     Set-Alias sdcd "C:\Users\আপনার-নাম\AppData\Local\SDC\sdcd.exe"
   মেলান:
     sdcd navaratna status
   (nr.* সুইচের তালিকা আসবে)
[Mac] /Applications/SDC.app/Contents/MacOS/ -এর ভেতরে sdcd* দেখুন।
সোর্স থেকে বানাতে চাইলে (যেকোনো ডিভাইসে; Rust দরকার - https://rustup.rs):
     git clone https://github.com/skilleddesk/SD-Code.git
     cd SD-Code\sdc\sdcd
     cargo build --release
   (target\release\sdcd.exe তৈরি হয়; বানাতে ১০–২০ মিনিট লাগে)

ধাপ ৫ - মডেলের আসল "ব্যবহারযোগ্য জানালা" মাপুন (N1-1)
------------------------------------------------------------------------------------------------
[সব]  Ollama চালু থাকা অবস্থায়:
     sdcd probe window --model qwen3.5:9b
  - মডেলকে বড় বড় প্রম্পটে শুরু/মাঝ/শেষের তিনটি তথ্য মনে রাখতে বলে; সবচেয়ে বড় নিরাপদ দৈর্ঘ্য মাপে।
  - ফল সেভ হয়: [Windows] %APPDATA%\sdc\models\qwen3.5_9b.toml   (দেখতে:  Get-Content $env:APPDATA\sdc\models\qwen3.5_9b.toml)
  - এরপর মডেলকে এর চেয়ে বড় প্রম্পট পাঠানো হবে না; দরকারে ভেঙে ছোট করা হবে।
  - সময় লাগে (কয়েক মিনিট; মডেল লোড হয়)। এ সময় অন্য ভারী কাজ করবেন না।
পুরো প্রোফাইল (টুল-কল, আউটপুট-দৈর্ঘ্য, গতি সহ) চাইলে:   sdcd probe qwen3.5:9b
  - এটা ফল দেয় "ক্লাস S/M/L"; ক্লাস L না হলে কিছু সুবিধা কম পাবেন।

ধাপ ৬ - SDC অ্যাপে সব ঠিক করুন
------------------------------------------------------------------------------------------------
দুটি আলাদা "Simple/Pro" আছে, গুলিয়ে ফেলবেন না:
  (ক) চ্যাটের মোড-বোতাম "Simple / Pro / Auto" (কতবার জিজ্ঞেস করবে):  এটা Auto রাখুন।
        কারণ ধাপ-এক্সিকিউটর শুধু Auto-তে চলে। Auto-তে শুধু বিপজ্জনক কমান্ড (delete, push, sudo, database) জিজ্ঞেস করে।
  (খ) Settings-এর "Mode: Simple / Pro" (কী দেখাবে):  Pro করলে "Advanced" ট্যাব আসে, যেখানে প্রতিটি সুইচ দেখা ও বদলানো যায়।
১. SDC খুলুন। একটি প্রজেক্ট ফোল্ডার খুলুন (নিজের মেশিনের লোকাল ফোল্ডার; server বা SSH ফোল্ডার নয়)।
২. মডেল বাছুন: Ollama -> qwen3.5:9b। মডেল-তালিকায় "class S/M/L · ১৬K context" দেখাবে। Q4 হলে পরামর্শ-লাইনও।
৩. মোড-বোতামে Auto বাছুন।
৪. Settings -> Mode = Pro, তারপর Settings -> Advanced খুলে সুইচ খুঁজুন:
     nr.fresh_step -> on        (এটাই ধাপ-এক্সিকিউটর চালু করে)
   সুইচ বদলানো নিরাপদ; ফেরাতে আগের অবস্থায় আনুন।
   Advanced ট্যাবে সুইচ না পেলে বিকল্প: পরিবেশ-চলক দিয়ে চালু করা (আমি Windows-এ যাচাই করিনি):
     [Windows]  [Environment]::SetEnvironmentVariable("SDC_V3_ENABLE","nr.fresh_step","User")
                তারপর SDC পুরো বন্ধ করে (tray থেকে Quit) আবার খুলুন। একাধিক হলে কমা দিয়ে: nr.fresh_step,nr.best_of_n
     ফেরাতে:      [Environment]::SetEnvironmentVariable("SDC_V3_ENABLE",$null,"User")
   কোন সুইচ চালু/বন্ধ দেখতে:   sdcd navaratna status   (এটা আপনার PowerShell-এর চলকই দেখায়, অ্যাপের Advanced-এর সেটিং নয়)

# Bakery shop program

## Background

This is a small bakery shop program written in Python.
The owner of the bakery sells rolls, cakes and coffee.
Every price in the program is a whole number of cents.
The shop is open every morning and the customers like the warm rolls best.
The program has no screen, no database and no network connection.
The owner looks at the code once a week, so every function stays short and plain.
Only the two files shop.py and cart.py are part of this job, and the tests folder stays exactly as it is.
The files already exist with placeholder functions that do nothing yet.
The shop keeps everything inside the shop and the owner works on one old computer.
The cakes are baked in the afternoon, the rolls in the early morning and the coffee all day long.
On Fridays the shop closes at noon, and on Sundays it stays closed for the whole day.

## Jobs

1. In shop.py, write the function total(prices) that returns the sum of a list of prices, and returns 0 for an empty list. The prices are whole numbers of cents.

2. In shop.py, write the function apply_discount(amount, percent) that returns the amount after taking off the percent, rounded down to a whole number of cents. A percent below 0 or above 100 must raise a ValueError with a short message.

3. In cart.py, write the function count(items) that returns how many items are in the cart, and returns 0 for an empty cart.

4. In cart.py, write the function cheapest(items) that returns the lowest price in the cart, and returns None for an empty cart. The items are plain whole numbers of cents.

১২.১ API key যোগ করা: মডেল-হাবের "API keys" ট্যাব। যে প্রদানকারীর মডেল চান তার key দিন। key কখনো চ্যাটে/ফাইলে/কমিটে পেস্ট করবেন না।
১২.২ Settings -> Agents:
     - ক্লাউড মডেল সারি যোগ করুন (provider:model, যেমন deepseek:deepseek-chat)।
     - প্রতিটি সারিতে "Role": যেকোনো কাজ / নকশাকার (একবার পুরো নকশা করে) / মেরামতকারী (ব্যর্থ ধাপ ঠিক করে)।
     - relay চালু করুন - সেটাই ক্লাউডে পাঠানোর আপনার সম্মতি। বন্ধ থাকলে একটি বাইটও ক্লাউডে যায় না।
     - সীমা (ডিফল্ট): প্রতি টার্নে ক্লাউডে সর্বোচ্চ ৬ ধাপ ও $0.25। বদলাতে rotation.toml-এর [relay] অংশ:
         [Windows] %APPDATA%\sdc\rotation.toml     (Get-Content $env:APPDATA\sdc\rotation.toml)
         max_cloud_steps_per_turn = 6     max_usd_per_turn = 0.25
     - একটি সারি 429/কোটা/key নেই/সময়-শেষ হলে সাময়িক বাদ পড়ে ও পরের সারি ডাকা হয়; ব্যবহারকারীর ক্রম বদলায় না।
১২.৩ প্রজেক্টে নিরাপত্তা (.sdc\policy.toml, প্রজেক্ট ফোল্ডারের ভেতরে):
         privacy = "local-only"            # এটা থাকলে কখনো ক্লাউডে যাবে না
         secret_paths = [".env", "secrets/**"]   # এই ফাইল কোনো মডেলকে পাঠানো হবে না
         protected_paths = ["package-lock.json"] # এই ফাইল ধাপ-এক্সিকিউটর বদলাবে না
     (সিনট্যাক্স নিশ্চিত করতে প্রজেক্টের আসল .sdc\policy.toml-এর উদাহরণ দেখুন।)
১২.৪ ক্লাউডে সত্যিই কী গেল দেখতে: প্রজেক্টের .sdc\audit\sent.jsonl (প্রতিটি পাঠানোর আগে লেখা হয়; সংখ্যা ও হ্যাশ থাকে, গোপন কিছু নয়)।
১২.৫ API key rotate: যে key আগে কোথাও দেখা গেছে (চ্যাট/লগ/স্ক্রিনশট) প্রদানকারীর সাইটে গিয়ে বাতিল করে নতুন বানান। (MEGHNA-র পুরনো বাকি কাজ।)
১২.৬ অন্য ইঞ্জিন (NAVARATNA-র অংশ নয়, Mac-এ ২০২৬-১০-২৪-এ দেখা অবস্থা; Windows-এ যাচাই করিনি):

"Ollama is not installed, or it would not start"
   -> ধাপ ২.২। নিজে চালান:  ollama serve   (আলাদা জানালায় খোলা রাখুন), তারপর অন্য জানালায় ollama list।
"model not found" / SDC বলছে মডেল ডাউনলোড হয়নি
   -> ollama pull qwen3.5:9b । SDC নিজেও নামাতে শুরু করে (Settings/Hub-এ অগ্রগতি দেখায়); শেষ হলে আবার পাঠান।
কিছুই এগোচ্ছে না / মেশিন আটকে যাচ্ছে / অনেক ধীর
   -> RAM/VRAM কম। অন্য অ্যাপ বন্ধ করুন; ছোট মডেল বা Q4 নিন; টাস্ক ম্যানেজারে "Memory" ১০০% হলে এটাই কারণ।
   -> Ollama থামাতে:  ollama stop qwen3.5:9b
"ContextOverflow: NeedsSplit ..." বা "NeedsSplit: the step's rules, goal and spec units alone are about N tokens"
   -> একটি ধাপের নিজের লেখাই জানালায় ধরছে না। অনুরোধটি ছোট ছোট স্বাধীন কাজে ভাঙুন, বা কম ইউনিট রাখুন।
"BLOCKED: ... holds no edit"
   -> মডেল FILE:/SYMBOL: ফরম্যাট মানেনি (মন্তব্য লিখেছে)। আবার চালান; বারবার হলে বড়/ভালো মডেল বা nr.best_of_n।
"BLOCKED: ... leaves something out" / "must define exactly the one symbol"
   -> মডেল কোড বাদ দিয়েছে বা একাধিক ফাংশন একসাথে লিখেছে; SDC নিজে ফেরত পাঠায় ও আবার চেষ্টা করে।
"BLOCKED: ... checks failed after your edit (it was undone)"
   -> প্রজেক্টের check (pytest) ব্যর্থ হয়েছে; SDC edit উল্টে দিয়েছে। ডেমোতে pytest ইনস্টল আছে কি দেখুন।
"... is protected by this project's policy" / "would carry a secret"
   -> .sdc\policy.toml-এর protected_paths-এ আছে, বা কোডে key-র মতো লেখা ছিল; ইচ্ছাকৃত নিষেধ।
"ধাপ-এক্সিকিউটর চালুই হচ্ছে না" (চ্যাটে "▸ NAVARATNA" লাইন নেই)
   -> চারটি শর্তই লাগে: (১) মডেল Ollama-র লোকাল মডেল, (২) মোড-বোতাম Auto, (৩) nr.fresh_step on, (৪) অনুরোধ ≥১৫০০ অক্ষর। এবং ফোল্ডার লোকাল।

পরের ভার্সন বানানোর নিয়ম (ডেভেলপার)
------------------------------------------------------------------------------------------------
  ১. Cargo.toml (sdc/sdcd ও sdc/app/src-tauri), package.json (sdc ও sdc/app), tauri.conf.json-এ ভার্সন বাড়ান; দুই Cargo.lock-এও (নিজের প্যাকেজ)।
  ২. CHANGELOG.md-র শীর্ষে নতুন "## [x.y.z]" অংশ।
  ৩. কমিট, `git push origin main`; GitHub -> Actions-এ CI সবুজ হওয়া পর্যন্ত অপেক্ষা (Windows জবও)।
  ৪. `git tag -a vX.Y.Z -m "X.Y.Z"` তারপর `git push origin vX.Y.Z`।
  ৫. release.yml Windows/macOS/Linux বানিয়ে সব ঠিক হলে রিলিজ প্রকাশ করে ও পুরনো রিলিজ মুছে দেয় (ফেরানো যায় না - তাই ভেবে করবেন)।
