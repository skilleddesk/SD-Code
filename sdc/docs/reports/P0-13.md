# P0-13 — Output compressor, OS-normaliser, command runner

**বাংলা সারাংশ:**
- `src/guard/`-এ তিনটি নতুন মডিউল (P0-3-এর facade ডকে যেখানে থাকার কথা লেখা ছিল, ঠিক সেখানেই):
  - **`compress.rs`** — output compressor। **চুক্তি:** যে লাইনটা failure signal, সেটা **কখনো বাদ পড়ে না**;
    বাদ পড়া লাইনের সংখ্যা জানানো হয়।
  - **`osnorm.rs`** — OS normaliser। একই tool call macOS / Linux / Windows-এ চলে: `grep`→`findstr`, path-এ separator,
    আর command string এই OS-এর shell-এ।
  - **`runner.rs`** — command runner। প্রতিটি command-এর deadline আছে; সময় পার হলে **পুরো process group** মারা হয়
    (`pty::kill_tree`), output ধরে রাখা হয়, আর `Ending::{Exited,TimedOut}` ফেরত দেয়।
- **যাচাই:** `guard::`-এ **৪১টি test**; পুরো suite **৯৮৪ পাস / ০ fail**।
- **যা মাপা যায়নি:** তিন OS-এ সত্যিই চালানো। এখানে শুধু macOS চলে, তাই per-OS mapping **পুরোটাই assert** করা হয়েছে
  (একটা ঠিক করে অন্যটা ভাঙলে test ফেল করবে) — এটা তিনটা মেশিনের চেয়ে **দুর্বল দাবি**, আর রিপোর্টে তাই বলা আছে।

## যে বাগগুলো test ধরিয়ে দিল (তিনটাই আমার নিজের, তিনটাই আসল)

1. **`dropped` সবসময় ০ দেখাচ্ছিল।** কম্প্রেসরে gap-counter আর total-counter একই variable ছিল; marker লেখার সময়
   সেটা `0`-তে reset হতো, তাই **যে log-এর শেষ লাইনটা error, সে "০ লাইন বাদ পড়েছে" বলত**। এখন দুটো আলাদা counter —
   এই কারণেই property test (২০০টি random input) লেখা হয়েছিল, একটা উদাহরণে ধরা পড়ত না।
2. **Windows path conversion macOS-এ কখনো চলত না।** `normalise_argument`-এ `MAIN_SEPARATOR != '\\'` গার্ড ছিল, অর্থাৎ
   macOS build কখনোই backslash বানাত না — কিন্তু ওটা ফাংশনের কাজই *অন্য* OS-এর জন্য normalize করা। গার্ড তুলে দিয়েছি।
3. **`looks_like_path` বেশি চালাক ছিল।** "২টার বেশি slash = sed expression" ধরায় `src/app/main.rs`-এর মতো আসল path-ও
   বাদ পড়ত। এখন সরল নিয়ম: URL (`://`), `key=value`, আর **trailing slash** (`s/a/b/`) বাদে যেকোনো `/`-যুক্ত argument path।

## নকশার সিদ্ধান্ত
- **`budget` বাইটে, লাইনে নয়** — cause একটি context window বাইটে খরচ হয়।
- **Signal line budget ছাড়িয়ে গেলেও রাখা হয়** — চুক্তি আকৃতির আগে। ফলে output budget-এর চেয়ে সামান্য বড় হতে পারে;
  এটাই সচেতন পছন্দ, নীরব লুকানো নয়।
- **`group_killed` দাবিটা যাচাই করা** — call করা হয়েছে কি না নয়, child সত্যিই মরেছে কি না (`try_wait`), তাই মিথ্যা দাবি হয় না।
- **`is_signal("0 failures")` ইচ্ছাকৃতভাবে true** — false positive কয়েক বাইট খরচ করে, false negative প্রমাণ হারায়;
  চুক্তি এক দিকেই চলে, তাই তালিকা রাখার দিকেই হেলে।
