**বাংলা সারাংশ:**
- `sdc/docs/UI-GUIDE.md` লেখা হয়েছে আসল কোড থেকে: ৭৩টি design token (dark/light), component তালিকা, string ফাইলের নিয়ম (English + Bengali)।
- `pnpm --filter @sdc/app smoke:visual` — headless Chrome-এ অ্যাপের দুটি আকার (desktop 1280×800, phone 390×844) × dark/light = ৪টি view-এর screenshot নিয়ে অনুমোদিত ছবির সাথে pixel-ভিত্তিক তুলনা।
- তুলনা কাজ করে প্রমাণিত: অপরিবর্তিত → ০.০০০%; ইচ্ছে করে বদলানো ছবি → ১৮.২% (ধরা পড়ে)।
- **সীমা (সৎভাবে):** শুধু অ্যাপ খুললে যে পর্দা আসে (Welcome dialog) কভার হয়েছে। প্রজেক্ট/daemon/provider লাগে এমন পর্দা backend ছাড়া headless browser-এ পৌঁছানো যায় না — প্রতিটি নতুন পর্দা (P0-15, P2-2, P3-9) নিজের view যোগ করবে।
- axe: ০ violation, ০ serious/critical। vitest ২৫২ পাস (UI-GUIDE সব token উল্লেখ করে কি না তার test সহ)।

## What changed
- `sdc/docs/UI-GUIDE.md` (new), `app/scripts/visual-bundle.mjs` (new, dependency-free PNG decode + diff), `app/tests/visual/*.png` (4 baselines), `app/tests/uiGuide.test.ts`, `smoke:visual` script.

## Measured
- two consecutive runs of one build: 0.000% pixels differ in all 4 views (byte-identical PNGs differ only in a metadata byte, hence the tolerance rather than equality).
- tampered baseline (a 300×200 block flipped): 18.23% differ -> CHANGED (limit 0.5%).
- `smoke:a11y`: 0 violations on the opening screen (dialog: Welcome to SDC).
- `pnpm --filter @sdc/app test`: 252 passed.
