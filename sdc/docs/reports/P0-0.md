# P0-0 — Plan Tracker and NEXT runner

**বাংলা সারাংশ:**
- `sdcd plan next | status | validate | sync | set` কমান্ড যোগ হয়েছে (`sdc/sdcd/src/plan.rs`)।
- Prompt Book থেকে ৬৬টি task পার্স হয়: ID, ক্রম, নির্ভরতা (`all P0` প্রসারিত), switch।
- `PLAN-STATUS.md` ও `GATES.md` তৈরি; gate `Result: PASS` না লেখা পর্যন্ত পরের phase শুরু হয় না।
- `validate` ধরে: ID অনুপস্থিত (Master Plan বনাম Prompt Book), অজানা নির্ভরতা, cycle, ভুল status, status ফাইলে সারি নেই।
- P0-0 শেষে `sdcd plan next` সত্যিই `P0-1` দেখায় (নিচে প্রমাণ)।

## What changed
- `sdc/sdcd/src/plan.rs` (new), `lib.rs` (`pub mod plan`), `main.rs` (`sdcd plan …` handled before the async runtime, like `bench`).
- `sdc/docs/PLAN-STATUS.md` (66 rows), `sdc/docs/GATES.md` (Gate 0-4 sections, empty), `sdc/docs/reports/`.
- The two plan files are copied into `sdc/docs/` (they were only in the project root `docs/`).

## Tests (`cargo test --lib plan::`, 9 pass)
mixed-status selection · failed gate blocks the next phase · in-progress resumes · blocked dependency is reported, not skipped ·
validator catches a missing ID, an unknown dependency and a cycle · status file round-trips · the real plan parses to 66 tasks and validates.

## Measured
`sdcd plan sync` -> 66 rows; `sdcd plan validate` -> `plan valid: 66 tasks`; after `plan set P0-0 done`, `sdcd plan next` -> `P0-1`.
Phase gate numbers: Gate 0..5 = not passed (nothing measured yet).

## Switch / risks
Switch: n/a (a new CLI subcommand only; no existing behaviour changed). Risk: `Depends:` lines are parsed as text — a new phrase
form (not `none`, `Gate N`, `all PN`, or IDs) would be read as an ID and `validate` reports it as unknown.
