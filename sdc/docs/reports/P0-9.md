# P0-9 — Model identity and Capability Probe

**বাংলা সারাংশ:**
- মডেলের পরিচয় এখন নাম নয়: `provider + digest + quantization + runtime version` (`ModelKey`)। এই চারটির যেকোনো একটি বদলালে সংরক্ষিত profile **provisional** (`M?`) — আবার probe করতে হবে।
- Probe (`sme/probe.rs`): ২৫/৫০/৭৫/১০০% গভীরতায় needle দিয়ে কার্যকর context, আউটপুটের সর্বোচ্চ নির্ভরযোগ্য দৈর্ঘ্য, ২০টি tool call (structured বনাম text-হয়ে-ছাপা), JSON-schema মানা, tok/s, TTFT, VRAM/GPU ভাগ, logprobs, thinking। S/M/L ক্লাস।
- Probe কোনো ব্যবহারকারীর ডেটা পাঠায় না: প্রতিটি প্রশ্ন seed + স্থির শব্দতালিকা থেকে তৈরি; একই seed = হুবহু একই প্রশ্ন (test)। env-এর secret প্রম্পটে ঢোকে না (canary test)।
- মডেল তালিকায় ক্লাস ব্যাজ (English + বাংলা): `class M? · 16K context`।
- `sdcd probe qwen3.5:9b [--quick] [--seed N]` কমান্ড; switch `models.probe` (ডিফল্ট বন্ধ)।
- **আসল Ollama এ চালানো হয়নি** (এই Mac-এ নেই): probe-এর যুক্তি একটি জানা-সীমার নকল মডেলে প্রমাণিত; Ollama-র JSON ফরম্যাট fixture-এ test করা; আসল সংযোগ আপনি হাতে যাচাই করবেন।

## Tests (all pass)
Rust, 16: the window a model really has is found (2k held, 4k lost); a holds-everything model measures at the top; needles move 25->100% and one miss fails the size; tool calls counted as structured / printed / missing; JSON adherence and output length; speed/VRAM/logprobs from the runtime; deterministic for a seed (byte-identical prompts) and different for another; nothing of the person's in a prompt; **changing digest, quantization or runtime makes the stored profile provisional**, another model has none; classes follow measurements; Ollama parsers (identity from tags/show/version, VRAM share from /api/ps, reply timings from NDJSON, request pins seed + temperature 0 + logprobs); a probed model carries its class in the list. App: typecheck, lint, vitest pass (label in en + bn).

## You verify by hand (needs Ollama)
1. `ollama pull qwen3.5:9b`; `sdcd probe qwen3.5:9b --quick` (full probe: without `--quick`, ~10-30 min). It prints the profile and saves it under `<data>/profiles/`.
2. Open the model list: the model shows `class S|M|L · NK context`.
3. `ollama pull qwen3.5:9b` again after an update (or change quantization) and re-list: the label gains `?` until you probe again.
4. Check `vram_bytes`/`gpu_share` equal what `ollama ps` shows; the 9B Q4 should be ~100% GPU on 8 GB.

## Honest limits
- The thresholds for S/M/L (12k/40k context, 0.8/0.95 tool reliability) are my choice, written in `classify`; they need tuning against your real numbers.
- The `models.probe` switch is declared but the probe is not yet run automatically on first use (that needs the model-selection path of P0-10); until then only `sdcd probe` measures.
