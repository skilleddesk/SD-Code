# P0-11 — Trustworthy benches

**বাংলা সারাংশ:**
- **নিয়ম কোডে** (`bench/rules.rs`): স্থির `--seed` (ডিফল্ট 20261017) ও `--temperature` প্রতিটি request-এ যায় ও `meta.json`-এ লেখা থাকে; smoke ছাড়া **কমপক্ষে ৩ রান** (নইলে error, `--allow-few-runs` দিলে বলে "noise-এর হিসাব নেই"); জোড়া রান → McNemar (`bench compare`, আগে থেকেই tested); **প্রতিটি রিপোর্টে noise** (কতগুলো task রানে রানে ফল বদলেছে + রানগুলোর pass rate-এর ব্যবধান); `--max-usd` বাজেট।
- **Machine-readable JSON:** `summary.json` (schema 1) + বাংলা `report-bn.md`-এ "Noise" লাইন।
- **Hard tier:** যে task baseline-এ ফেল/ফ্লিপ করেছে (`ml-bn`) + **আপনার নিজের গোপন task** `tasks/private/`-এ (git-ignored, কখনো commit/publish হয় না; বাস্তব প্রজেক্টের ফোল্ডারকে fixture বানানো যায়; `sdcd bench private` দেখায় কোথায় ও উদাহরণ)।
- **ছোট-মডেল bench (tier `small`, ৮টি):** ৩০ অধ্যায়ের ডক থেকে উদ্ধৃতিসহ প্রশ্ন; multi-file feature (priority); ২৪ ফাইলে rename; কেটে যাওয়ার-ঝুঁকির লম্বা function (৪০টি রূপান্তর); বাংলা ও Banglish নির্দেশ; context-সীমার কাছাকাছি ফাইল (~২০k token); test-ছাড়া প্রজেক্টে edit। সবকটি `sdcd bench validate`-এ প্রমাণিত: untouched = ফেল, reference = পাস (৮/৮)।
- `small` tier `full`-এর অংশ নয়, তাই সব baseline-এ "৪০টি task"-এর মানে বদলায়নি।

## Not done / honest limits
- "Temperature per Step Profile": Step Profiles do not exist until P1-4; until then the temperature is a bench flag (default: the model's own). The hook is `rules::apply`.
- The small-model bench is **validated, not run**: it needs a local 8-9B model (no Ollama here). Run it yourself: `sdcd bench run --models ollama:qwen3.5:9b --tier small --runs 3`.
- The private-task mechanism is tested with a temp folder; no real private task of yours exists yet.
- The near-limit file is ~20k tokens by estimate (2,076 lines); its exact token count depends on the tokenizer.
