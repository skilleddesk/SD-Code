# P0-14 — Sandbox Runner and Step Transaction

**বাংলা সারাংশ:**
- **Sandbox Runner** (`guard/sandbox.rs`, switch `exec.sandbox`): Verify-এর যে checks চলে (test, build, script) সেগুলো প্ল্যাটফর্মের sandbox-এ চলে — প্রজেক্টের বাইরে লেখা নিষেধ, network বন্ধ (প্রজেক্ট `policy.toml`-এর `sandbox_network = ["ip:port"]` দিয়ে খুলতে পারে), CPU-সময় ও ফাইল-আকারের সীমা, credential ফোল্ডার (`~/.ssh`, `~/.aws`…) পড়া নিষেধ।
- **ওএস অনুযায়ী সৎ গ্যারান্টি** (`sandbox::guarantees()`): **macOS** `sandbox-exec` — লেখা + network **enforced** (এই Mac-এ আসলে চালিয়ে প্রমাণিত); **Linux** `bwrap` থাকলে সব enforced, শুধু `unshare` থাকলে network enforced কিন্তু লেখা **নয়** (বলা আছে), কিছু না থাকলে শুধু সীমা; **Windows** — filesystem/network isolation **নেই** (রিপোর্ট করে; অচেনা কোড চালাবেন না)।
- **Step Transaction** (`runtime/transaction.rs`, switch `edit.transaction`): ধাপের সব বদল shadow কপিতে; Verify সবুজ হলে তবেই আসল ট্রি-তে, journal-আগে-লেখা প্রোটোকলে (প্রতি ফাইল atomic rename); লাল হলে আসল ট্রি-র একটি byte-ও বদলায় না; মাঝখানে অন্য কেউ ফাইল বদলালে `Conflict` (কিছুই লেখে না)।
- **`kill -9` মাঝপথে:** চাইল্ড প্রসেস কমিটের প্রতিটি মুহূর্তে (pre-image ×৬, journal, apply ×৬, committed) abort হয় — ১৪টি বিন্দু; প্রতিটি পরে `recover` আগের ট্রি (বা `committed` হলে নতুন ট্রি) ফেরত দেয়, **কখনো মিশ্র নয়**। নিয়ন্ত্রণ: recover-এর আগে `apply:1..5` বিন্দুতে সত্যিই মিশ্র অবস্থা থাকে (test নিজে প্রমাণ করে)।
- প্রতিটি সফল commit একটি Time Machine point (`commit_with_point` → shadow-git checkpoint)।

## Honest limits
- **Windows has no isolation** (see above); **Linux was not run** here (only the argument vectors are tested) - bubblewrap behaviour needs your check on a Linux box.
- The build tools' own caches (`~/.cargo`, `~/.npm`, `~/Library/Caches`, … `TOOL_CACHES`) are writable so honest builds work; a hostile check could leave something there. Everything else outside the project is refused.
- macOS cannot limit memory (the kernel ignores `ulimit -v`); `sandbox-exec` is deprecated by Apple but is what the OS ships; the macOS network allow-list takes `ip:port`, not host names.
- The transaction is a tested module; the agent's own edit tools still write the real tree directly (with checkpoints). Making the step runtime use it is **P1-2 "patch in transaction"** by the plan; until then the half-committed-step recovery runs at the start of each turn but there is nothing yet that begins a transaction in production.
- The shadow copy skips files over 8 MiB and `.git`/`.sdc`; dependency folders are linked, so a check that writes `target/` writes the real one.
